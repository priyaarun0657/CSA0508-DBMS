# Task 10 – Data Model Comparison

- File-based model: duplicated descriptions and update anomalies.
- Hierarchical model: tree navigation restricts many-to-many paths and repeated loan occurrences.
- Network model: owner-member sets allow multiple paths but are navigation-dependent.
- Relational model: declarative constraints, joins and views support shared conceptual data.
- Three-schema architecture: operational views, conceptual relations, internal indexes/storage.
