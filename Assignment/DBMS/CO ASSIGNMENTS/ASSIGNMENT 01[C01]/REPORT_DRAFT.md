# Assignment Report Draft

This report proposes a relational/EER model for Meridian Museum that separates identity, ownership, custody, exhibition placement and condition evidence. The preferred model uses shared PERSON identity, independently identified LOAN occurrences, LOAN_OBJECT lines, weak DISPLAY_SLOT records, and condition reports linked to artifacts and loan context. The changed shared-ownership requirement is addressed by temporal ARTIFACT_OWNERSHIP records.
